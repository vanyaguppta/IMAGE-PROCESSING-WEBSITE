# Dynamic Image Processing Lab Website

Developed by:- Vanya Gupta

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Upload any JPG/PNG image.
4. Select a practical from the left sidebar.
5. Run operations. The original and processed images are shown together.

No Node.js, npm, Python, backend, or internet connection is required.

## Included practical functionality
- Basic image operations
- RGB/grayscale and colour-channel exploration
- 2-D geometric transformations
- Histogram equalization and enhancement
- Averaging, Gaussian, median and bilateral-style filtering
- Noise generation and denoising workflow
- PNG/JPEG compression plus RLE/LZW analysis
- Binary morphology: erosion, dilation, opening, closing, gradient, top-hat, black-hat
- Correlation/template object detection
- Sobel, Prewitt and Canny-style edge detection

## Important
This is a browser-only educational implementation. Some advanced OpenCV operations (especially exact bilateral filtering, full Canny stages, Telea/Navier-Stokes inpainting, and some morphology variants) are represented as browser demonstrations/approximations rather than byte-for-byte OpenCV equivalents.
